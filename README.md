# Static_ML_Vertex_Reconstruction

## Static Machine-Learning Vertex Selection for TeBAT Time-Projection-Chamber Event Reconstruction
This repository contains the code, data products, trained models, and analysis scripts used to develop and evaluate a static machine-learning vertex-selection method for TeBAT time-projection-chamber event reconstruction. The method is designed to improve reconstructed nuclear-reaction vertices by selecting the best candidate vertex from a set of Hough/BMeleton-derived geometric candidates. Rather than continuously adjusting or refitting the vertex position with a neural network, the algorithm generates several physically motivated vertex candidates for each event, computes topology- and geometry-based features for each candidate, and uses an ExtraTrees regression model to predict each candidate’s expected distance from the true simulated vertex. The candidate with the lowest predicted error is then selected as the reconstructed event vertex.

The repository includes the full workflow used for training and validating the static-ML model on simulated TeBAT events, including candidate-feature generation, balanced multi-dataset 70/30 train-test splitting, model training, model application, residual analysis, oracle-candidate comparisons, feature-importance studies, and publication-style plotting. The included simulated datasets cover several reaction and gas-pressure configurations, including 14O(alpha, alpha)14O at multiple pressures and 14O(p, p)14O elastic scattering. Associated ROOT truth files and reconstructed Hough-line inputs are used to quantify vertex residuals in x, y, z, and total 3D distance.

In addition to the simulation-based training and validation workflow, this repository includes scripts used to apply the trained vertex-selection model to experimental alpha-scattering data. These scripts reconstruct alpha-particle kinetic energies, calculate elastic-equivalent center-of-mass energies, compare static-ML and Hough-only vertex reconstructions against a common SRIM-based kinematic curve, and perform paired residual comparisons between reconstruction methods. Supporting files include detector maps, silicon calibration parameters, event-mapping tables, exclusion lists, SRIM stopping-power tables, and scripts for enforcing common event sets between compared methods.
The purpose of this repository is to provide a reproducible record of the static-ML vertex-selection analysis used in the associated publication. It is organized to allow users to regenerate candidate-feature tables, reproduce the train/test split, retrain the model, apply the model to held-out simulation or experimental data, and recreate the residual and SRIM-comparison figures used in the analysis.
